# EP's Glam & Fashion

> *"Celebrating real beauty, building lasting confidence."*

Full web application for **EP's Glam & Fashion** (Koforidua – Akwadum, Ghana).
- `login.html` — Google One-Tap & Email/Password authentication gate
- `index.html` — Main client website (services, GH₵ prices, service gallery, booking, 10-circle loyalty card)
- `admin.html` — Dedicated admin studio sharing the same Firebase database & login session
